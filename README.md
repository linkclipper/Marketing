# LinkClipper Marketing

Growth strategy. Rule for this repo: **marketing may never overclaim** — screenshots come from the real harness (see `brand/README.md` regeneration rules), copy describes shipped behavior only. The store listing copy is reviewed in `Knowledgebase/runbooks/cws-submission.md`; this repo is about *channels and positioning*.

## Positioning

- **One line:** *Save the web you love. Find it again, in one place.*
- **Category we sit in:** bookmarks/reading-list tools, not social media (until discovery ships).
- **Honest differentiators:** in-place replay (reader + floating player), local-first (no account wall), in-page saves where you actually watch.
- **Never position as:** a Pinterest clone; a privacy certification; anything with "AI" in the name.

## Audiences

1. Power readers/researchers (articles, docs, papers) — the Reader is the pull.
2. Video-first people (Shorts/reels collectors) — the in-page save button is the pull.
3. Browser-decentralists (Brave/privacy crowd) — local-first + user-owned sync is the pull.

## Launch sequence (does not start until CWS listing is live)

- **Phase 0 (now):** nothing public except repo/site; asset library grows via `brand/`.
- **Phase 1 — store live:** submit to extension roundups (Chrome Web Store edit suggestions, "cat and mouse"-free lists like Browser extensions lists on GitHub), r/chrome_extensions-style communities; Show HN when the share-links story (Phase B) has a demo.
- **Phase 2 — Phase B shipped:** the public board page doubles as the demo artifact — every shared board is a landing page for us.
- **Phase 3 — discovery (C):** creators discovery/curators is the growth loop (found boards → remix → borrowed saves).

## Copy bank (approved lines)

- "Save the web you love. Find it again, in one place."
- "Boards for videos, reels and articles — playable and readable in place."
- "Your data lives in your browser. Sync only to your own project."

## Rules

- Every launch artifact references a real release tag (`vX.Y.Z`), never "0.3.0-ish".
- No growth experiments that change UX (nudges, interstitials) — dashboard is sacred.
- Press/support questions route to `support@linkclipper.app`.
